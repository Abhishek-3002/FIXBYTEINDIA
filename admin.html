Program rules

₹12,000 in valid purchases within four consecutive calendar days earns one ₹99 static website reward. Paid and credit bills count. Returns reduce totals; cancelled bills do not count. Each reward cycle is separate.

FIXBYTE INDIA is the only admin operator. CMADD has no separate dashboard. FIXBYTE manually records bills and manually controls each store's CMADD connection status.

Four-day eligibility rules

  • First bill starts a four-calendar-day cycle.
  • ₹12,000 net valid bill total earns one reward.
  • Paid, credit and partial-payment bills count.
  • Returns subtract from the cycle total.
  • Cancelled bills are excluded.
  • Backdated entries are blocked to protect cycle calculations.
  • Once a reward is earned, the next cycle begins with a later-day bill.
If a return is recorded after a reward was earned, the cycle is flagged for manual review rather than silently removing an already issued offer.
